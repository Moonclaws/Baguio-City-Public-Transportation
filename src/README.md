# Source Code (`src/`)

Source code for the Baguio City Public Transportation system.

## What goes here

The reusable logic that powers the system — separate from experiments
(in `notebooks/`) and from data (in `data/`).

## Modules

- `data_loader.py` — load jeepney route data from a file
- `recommender.py` — match jeepney routes to a destination

Starter modules created for Laboratory Session 1.
