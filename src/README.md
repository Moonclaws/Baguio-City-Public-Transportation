# Source Code (`src/`)

Production code for the Baguio City Public Transportation system.

## What goes here

The reusable logic that powers the system — separate from experiments
(in `notebooks/`) and from the user interface (in `website/`, added later).

## Modules

- `data_loader.py` — load jeepney routes and passenger data
- `recommender.py` — match and rank jeepney routes for a destination
- `demand_model.py` — predict passenger demand by time of day (Lab 2+)

## Status

Starter modules created in Lab 1. Full implementation in Lab 2+.
